# Reserva HT Brasília

App que abre o formulário de reserva do Hotel de Trânsito de Brasília já preenchido.

Uso: https://danielsoaresbarboza-debug.github.io/reserva-ht-brasilia/

Os dados de cada pessoa ficam salvos só no próprio aparelho; nada é enviado para este repositório. CPF e Identidade são digitados direto no formulário.
